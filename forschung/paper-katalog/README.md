# Paper-Kartografie

Arbeitskatalog (Forschung, nicht automatisch publiziert). Original-Paper bleiben unverändert; Metadaten und neue Volltexte werden separat versioniert. Rohchats werden nicht automatisch in das öffentliche Repository kopiert.

Normen: RO-Crate 1.2, DataCite 4.7, W3C PROV-O, FAIR.
