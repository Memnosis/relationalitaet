Minimal-KI · Die kleinste KI der Welt

Die zentrale Frage lautet nicht, wie viele Befehle wir sammeln, sondern welche minimalen ausführbaren Funktionen zusammen bereits ein lern- und handlungsfähiges System bilden.

Input → Zustand → Regelauswahl → Operator → Output → Fehlerprüfung. Vier Kernfunktionen: Gedächtnis, Regelverdichtung, Komposition und Rückkopplung.

Stand: Architektur beschrieben; integrierter Ende-zu-Ende-Lauf nicht nachgewiesen.
