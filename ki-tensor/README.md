## Aufbau
- [audit/BESTANDSAUDIT.md](audit/BESTANDSAUDIT.md): belegter Status, Quellen-/Zählebenen, offene Validierung.
- [audit/kennzahlen_audit.json](audit/kennzahlen_audit.json): maschinenlesbarer Status.

- `daten/trinitaeten/`: quellentreue Originaltrinitäten und Kandidaten.
- `daten/nicht-passende/`: begründete Nichtpassungen, Verwerfungen, Gegenbeispiele.
- `codebuch/`: Codes, Tensorachsen, Feldakten, Hypothesen.
- `pipeline/`: Parser, Importer, Relationsprüfer.
